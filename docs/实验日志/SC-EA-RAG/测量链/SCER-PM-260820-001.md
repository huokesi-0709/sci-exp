# E0功率测量链实验日志：E0_session001

## 目的

验证INA226、ESP32-S3采集时钟、Windows串口采集、Radxa查询边界标记和硬件状态采样，
是否具备论文级单查询物理能耗积分的基础条件。

## 已实际完成

1. ESP32-S3以目标100Hz输出INA226功率样本，并由Windows COM18、921600 baud采集。
2. 形成约60分钟稳定性分析报告：378,348个样本、3809.973秒、有效采样率
   99.304Hz、序列缺失0、回退0、最大间隔17.026ms、质量标志0。
3. 完成`E0_idle_101`、`E0_idle_102`、`E0_idle_103`三段约65秒空闲基线；聚合平均
   功率1.280542W，段间SD 0.004747W。
4. 完成381次同步样本，RTT P99 6.1074ms。
5. 完成100次外部标记RTT测试，错误0，P50 8.6018ms、P95 12.3543ms、
   P99 14.9123ms、最大21.2460ms。
6. 完成229.988秒Radxa硬件状态记录，共1089条；未观察到thermal throttling。

## 当前门槛结果

预校准报告中除`calibration_pass=false`外，当前已编码的软件门槛全部通过；因此
`e0_pass=false`。这是一份部分完成记录，不能宣称E0正式通过。
