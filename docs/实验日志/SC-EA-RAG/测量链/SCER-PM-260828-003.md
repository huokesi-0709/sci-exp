# E1前置：5V/3A充电头换源空闲预检

## 目的与边界

本会话仅确认将实际运行供电由UTP切换为标称5V/3A充电头后，Radxa空闲时的电压与INA226质量标志。
它不改变已完成的E0校准状态，不执行`RESET_CAL`、`ZERO`或`CAL`，也不构成E1正式结果。

## 接线与命令

充电头接INA226 `VIN/GND`；INA226 `VOUT/GND`经既有20AWG Type-C红黑线接Radxa供电口；ESP32-S3
经USB CDC接Windows。电子负载和ANENG未接入。

```powershell
.venv\Scripts\python.exe scripts\采集INA226串口功率.py `
  --serial COM18 `
  --baud 921600 `
  --output D:\sci-exp-data\E1_preflight_20260828\INA226_source_5V3A_radxa_idle_001.full.jsonl `
  --marker-host 127.0.0.1 `
  --marker-port 8765
```
