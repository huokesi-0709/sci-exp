# E0：0.5A供电链压降定位

## 条件与读数

电子负载旋钮约0.5A，风扇未转；UTP3313无其他输出负载，处于CV模式。

|项目|读数|
|---|---:|
|UTP输出端子 U0|5.00V|
|INA226 输入 U1（VIN-GND）|4.54V|
|INA226 输出 U2（VOUT-GND）|4.53V|
|ANENG显示 U3|4.328V|
|UTP电流，三次|0.634A / 0.634A / 0.634A|
|ANENG电流，三次|0.492A / 0.523A / 0.523A|

## 压降分段

|路径|压降|判定|
|---|---:|---|
|UTP端子 → INA226输入，U0-U1|0.46V|主要异常；输入USB-A转接、细红黑线或接触点阻抗过高|
|INA226输入 → 输出，U1-U2|0.01V|未发现显著异常；与R010在约0.6A下的毫伏级压降相符|
|INA226输出 → ANENG显示节点，U2-U3|0.202V|显著异常；输出USB-A母座/引线/接头存在高阻或接触不良|
|UTP端子 → ANENG显示节点，U0-U3|0.672V|负载侧仅4.328V，远低于E0的4.75V门槛|

## 结论与处置

本次诊断表明主压降不在INA226分流路径，而在前后两段USB-A转接链。UTP电流稳定为0.634A，
ANENG读数在0.492A至0.523A间变化，二者差0.111A至0.142A；在未确认其测量节点与准确度前，
ANENG当前不能作为E0的可信电流参考。ANENG显示点未必是电子负载最终输入点，实际负载端电压
可能更低。

后续先关闭输出、更换为短而粗的输入/输出供电线和可靠USB-A母座，优先使用UTP附带测试线直接
连接INA226 VIN/GND；修复后只重做0.5A节点电压定位。确认U3在实际负载下至少4.75V且电流参考
一致之前，不执行ZERO、CAL或正式三点采集。

## 方法学决定：UTP3313运行参考（用户选择方案1）

用户于2026-08-28明确选择将`UNI-T UTP3313TFL-II`的稳定面板电流读数用作本项目E0的
**厂家指标运行参考**。依据为厂家说明书：电流设定分辨率为`1mA`，在`25°C±5°C`时电流设定
准确度为`<0.5% + 5mA`。说明书来源：
https://instruments.uni-trend.com.cn/static/upload/file/20241127/UTP3313TFL%20UTP3315TFL%E4%B8%AD%E6%96%87%E8%AF%B4%E6%98%8E%E4%B9%A6REV.2(20210818).pdf 。

该决定并不把UTP升级为计量溯源参考：当前无校准证书，且厂家页面描述的是**设定准确度**，未单独

固定接线和同一协议下比较相对物理能耗；不得称为“计量级绝对准确度”“经认可实验室校准”或

三点的**电压**参考不能取UTP端子的5.00V设定值：那一读数在INA226之外，包含输入线压降。改用
