> 本地、非商业科学研究、仅研究人员内部使用、不出版或公开分发受限来源正文及其派生切块。

在该边界下，15份来源（13份中文来源、2份WHO来源）均已完成文件存在性、
SHA-256、内部研究使用依据、正式库处置、内容范围和版本链登记，冻结检查结果为：

这里的“冻结通过”只表示可以启动内部正式数据构建、正式标注和Radxa实验，

`公开再分发资格=false`来源的正文和派生切块，只公开来源元数据、哈希、
生成脚本和由用户自行下载后构建的流程。

## 2. 许可与镜像结论

### 2.1 WHO来源

| 来源 | 可引用证据 | 正式库处置 | 公开再分发 |
|---|---|---|---|
| `WHO_ICRC_BEC_2018` | 官方PDF版权页第4页标明`CC BY-NC-SA 3.0 IGO`；[官方出版页](https://www.who.int/publications/i/item/9789241513081) | 仅作标注参考，不进入中文公众直接检索 | 有条件允许：非商业、署名、相同方式共享、不得使用WHO/ICRC标识，第三方材料另核 |
| `WHO_PFA_2011` | 官方PDF版权页第2页为`All rights reserved`；[官方出版页](https://www.who.int/publications/i/item/9789241548205) | 仅保留元数据和标注参考，不进入直接检索 | 不允许；复制或翻译须另行申请WHO许可 |

两份WHO材料不能沿用同一个许可证结论。此前把WHO PFA误记为CC许可的字段已修正。

### 2.2 中文来源的内部研究依据

除两份官方规章/命令外，其余中文网页、科普材料和指南均未发现明确开放许可或
公开再分发授权。内部研究使用依据登记为《中华人民共和国著作权法》第二十四条
第（六）项规定的科学研究少量复制边界，并同时执行署名、不出版发行和不公开派生
切块的限制。[现行著作权法官方文本](https://www.npc.gov.cn/c2/c30834/202011/t20201119_308796.html)

`MEM_HIGHRISE_FIRE_ORDER5`和`CMA_WARNING_SIGNALS_ORDER16`属于官方规章/命令，
按著作权法第五条的官方文件排除规则登记；公开时仍只保留官方文件正文、来源、
文号和有效状态，不包含网页设计、图片或第三方材料。

### 2.3 镜像证据

| 来源 | 镜像结论 |
|---|---|
| `NHC_PSYCHOLOGICAL_HOTLINE_2021` | 国家心理健康中心镜像可验证来源沿袭，但镜像页面没有授予公开再分发权 |

“镜像可访问”只证明来源关系和可获取性，不等于著作权授权。

## 4. 96条正式双审与仲裁

冻结通过后，96条候选已完成两名审查者独立判断和研究者仲裁：

| 结果 | 数值 |
|---|---:|
| 风险等级完全一致率 | 0.9375 |
| 风险等级Cohen's κ | 0.897253 |
| L3二元判断完全一致率 | 1.0000 |
| L3二元判断Cohen's κ | 1.0000 |
| 回退判断完全一致率 | 0.947917 |
| 回退判断Cohen's κ | 0.891599 |
| 证据集合平均Jaccard | 0.7500 |
| 最终风险分布 | L0=9，L1=28，L2=53，L3=6 |
| 最终回退分布 | C3/回退=38，非回退=58 |
| 域外对照 | 3 |
| 最终`source_group_id` | 21组 |

正式仲裁相对冻结前复核修正了12条风险标签、7条回退标签和87条证据集合。
证据集合的大量变化主要来自将通用证据替换为与呼吸困难、出血、头伤、
挤压/被困、低温、资源缺乏、心理支持和低电量场景直接对应的协议切块。

正式分组已按“最终事件簇｜最终协议家族｜协议版本”重新计算，不再沿用旧证据绑定
下的17组，最终得到21组。否定范围也已修正，例如“头晕但没有头部出血”不再因
否定短语中的“出血”误升为L3，“不是喘不上气”不再触发呼吸困难L3。

## 5. 样本量复核

96条样本足以冻结标注规则、发现系统性误标并估计双审一致性，但不足以作为论文
主实验的最终测试集：

| 指标 | 当前/建议 |
|---|---:|
| 当前样本量 | 96 |
| 当前独立来源组 | 21 |
| 当前L3 | 6（6.25%，95% Wilson CI 2.90%–12.97%） |
| 当前C3 | 38（39.58%，95% Wilson CI 30.38%–49.58%） |
| 最坏情形下比例95%CI半宽≤5%的最低样本量 | 385 |
| 建议主测试集 | 至少400条 |
| 建议独立`source_group_id` | 至少40组 |
| 建议L3富集样本 | 至少100条 |
| 建议C3样本 | 至少100条 |
| 建议域外对照 | 至少30条 |

若按当前6.25%的自然L3比例抽样，要观察约60条L3需要约944条总查询，因此正式集
必须采用预先声明的L3分层富集，而不能只依赖自然抽样。
