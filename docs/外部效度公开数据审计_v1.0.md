# 外部效度公开数据审计 v1.0

审计日期：2026-07-28。

## 结论

HumAID、HumSet和TREC Incident Streams都能补充当前400条研究者编写场景
缺少的自然语言、事件和地区变化，但三者都不是“公众向应急RAG提问并附带权威
答案”的数据。因此，本项目只继承其文本分布、事件元数据或原任务标签，不继承
安全答案、严重失效、行动完整率或可接受配置标签。所有外部文本仍须重新绑定适用
协议并进行双审。

CrisisNLP Actionable Requests and Offers同时含真实社交媒体请求/供给和合成数据，
是目前最接近“准真实需求表达”的候选；真实和合成部分必须分开报告。

## 推荐的外部数据角色

1. `external_adaptation`：只用于词表、编码器适应、阈值前的开发诊断，不接触
   最终封存事件。
2. `external_sealed_test`：按事件整体封存，模型、提示、阈值和配置冻结前禁止
   查看系统结果。
3. `audit_only`：许可未清、无法绑定适用协议或隐私风险过高的记录。

事件、原记录、规范化文本和扰动父样本都不得跨适应集与封存测试集。封存测试必须
按事件而非按记录随机划分。

## 已落地的数据约束

- 登记表：`data/external/外部数据登记_v1.0.csv`
- 记录Schema：`data/schemas/外部查询记录_v1.0.schema.json`
- 审计脚本：`scripts/审计外部查询自然度与泄漏.py`
- 必填噪声、歧义、脆弱需求和扰动父样本字段。
- 分别统计自然/准自然/研究者改写/合成来源。
- 默认限制单一来源不超过60%，单一显式或推断模板不超过20%。
- 官方压缩包SHA-256：
  `b42077b3b46e49a84ce162041e94562b5582cd74be8fc0501e773fef8427b42d`。
- 307条真实文本中229条自动遮盖了URL、账号、电话或邮箱；248条有Sandy/NYC
  线索，59条仍需人工确认事件归属。
- 当前适应池模板最大占比约0.65%，但单一来源占100%，来源集中度门槛未通过。

## 未解除的硬门槛

- 未替用户接受HumAID/TREC的数据使用协议。
- HumAID与TREC-IS仍未下载；Requests/Offers已按其CC BY-NC-SA 4.0页面许可下载。
- 未建立外部记录的中文协议答案标签。
- 未确定适应集100条和封存测试500条是否仍为最终规模。
- 未做真实问询数据的伦理审批或豁免判定。

在这些门槛解除前，400条开发集的结果必须表述为“协议约束、研究者编写场景上的
内部效度”，不得外推为真实公众问询性能。
