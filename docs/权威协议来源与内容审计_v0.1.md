# 权威协议来源与内容审计 v0.1

日期：2026-07-27  
状态：候选来源和派生章节已审查，禁止作为正式知识库

## 1. 本轮完成内容

当前登记15份权威材料，均已落盘并生成SHA-256。新增材料覆盖头部外伤、低温症、
挤压伤、地震砸伤、高层火灾、心理支持、灾区饮水和“三断”通信。对被官方站点
反爬拦截的两份材料，分别采用国家心理健康和精神卫生防治中心、FAOLEX所保存的
同版PDF作为下载镜像，登记表仍保留原始发布页面与实际下载地址。

已完成：

- 来源机构、页面、版本、辖区、适用对象和镜像关系登记；
- 原文件或网页转文本副本落盘；
- 下载报告与本地文件SHA-256回填；
- 章节/页码级确定性筛选；
- 600字符目标长度、80字符重叠的精选切块；
- 24条先导查询的机器建议、两轮独立审查与仲裁；
- 风险动作、专业边界和跨灾种误用检查。

所有原始来源与精选切块仍为 `draft`。当前产物不得改名为
`data/processed/protocols.jsonl`，不得用于正式训练、校准、测试或论文结果。

## 3. 派生结果

- 13份来源进入章节级直接检索；
- 2份专业/英文材料排除直接检索；
- 生成64条精选候选切块；
- 24条先导查询中，23条仲裁为至少有一条直接或部分证据；
- 唯一无证据条目是预设域外对照“你能帮我写诗吗”。

原始宽范围切块仍仅用于历史审计；新增来源以章节级派生结果为当前有效候选，
避免把整页导航、相邻主题和专业操作混入检索库。

## 4. 已识别的高风险内容

自动扫描只负责提示，最终取舍以章节规则和双审记录为准。

- 地震发布会中的饮用尿液建议继续排除；
- WHO BEC专业流程继续排除公众直接生成；
- 低温症中的主动加热、饮水和CPR必须结合意识、严重度和施救能力；
- 挤压伤中的解除压迫不能脱离受压时长、现场安全和专业救援条件；
- 头伤材料中的开放气道手法、搬运和医疗流程未进入精选片段；
- 地震救护材料中的糖盐水、扩容和尸体处置未进入精选片段；
- 心理热线指南中的诊断、自杀量化评估、治疗和随访流程不进入公众动作；
- 高层火灾、洪水和地震被困条款不得跨灾种机械互换；
- 气象预警阈值具有属地性，不能解释为所有地区的即时统一阈值。

## 5. 双审结果

24条记录已完成两轮审查和仲裁：

- 查询风险等级κ=1.000；
- 回退判断κ=0.833；
- 证据集合平均Jaccard=0.729；
- 11条进入安全回退或澄清；
- 机器Top-3对23条有证据记录的平均Recall@3为0.826。

证据增加没有自动降低风险。例如，两条挤压查询仍为L3并转专业救援；“我没水”
已有水源安全证据但仍须澄清时长和症状；低电量已有通信证据但仍只是配置约束。
