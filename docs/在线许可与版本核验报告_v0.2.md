# 在线许可、镜像授权与版本核验报告 v0.2

> 历史在线访问记录，最终处置见`许可版本冻结与96条正式双审报告_v1.0.md`
> 和`data/annotations/许可与版本核验表_v1.0.csv`。

核验日期：2026-07-28  
核验环境：可访问官方站点的 Windows 环境  
核验范围：15 份已下载并登记的权威来源，其中 13 份中文政府/镜像来源是本轮重点补证对象。

## 结论

- 15/15 份来源均已完成本地文件存在性和 SHA-256 校验。
- 12/15 个官方页面返回 HTTP 200；3 个国家卫生健康委员会页面返回 HTTP 412。
- 15/15 个官方页面记录为“未发现明确开放许可/再分发条款”。
- 15/15 个镜像授权字段记录为“未发现明确镜像授权”。
- 15/15 份来源均已写入独立的在线版本证据字段，包括登记版本、HTTP 状态、页面标题和 Last-Modified（若页面提供）。
- 页面可访问、版权声明或可下载性均未被解释为再分发许可。

- `data/annotations/许可与版本核验表_v0.3.csv`
