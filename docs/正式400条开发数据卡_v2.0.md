# 正式400条开发数据卡 v2.0

## 数据集身份

| 字段 | 内容 |
|---|---|
| 名称 | 离线应急RAG正式400条开发金标准集 |
| 版本 | v2.0分层冻结；文本输入v1.1 |
| 角色 | `development_gold_not_confirmatory_3600` |
| 语言 | 中文 |
| 查询数 | 400 |
| 独立来源组 | 65 |
| 权威协议切块 | 64 |
| 协议来源 | 13个政府/权威来源 |
| 个人数据 | 无真实用户、无可识别个人信息 |

本数据用于标注规则、检索、路由、校准流程、Windows预处理和Radxa工程联调。
它不能替代研究协议v2.0规定的3,600条最终核心数据。

## 内容与设计配额

查询覆盖地震、建筑安全、火灾、洪涝、滑坡、极端天气、伤害急救、心理支持、
资源中断及明确域外请求。

| 标签 | 数量 |
|---|---:|
| L0 | 36 |
| L1 | 81 |
| L2 | 181 |
| L3 | 102 |
| 应C3回退 | 105 |
| 域外对照 | 30 |

这些比例是安全关键开发集的设计配额，不代表现实灾害中的风险或请求分布。

每条查询包含灾种、查询类型、L0–L3、C3、`gold_evidence_ids`、必需行动、
禁止行动、事件簇、协议家族、版本链、双人审查和仲裁状态。

17条完全重复的域外文本已在v1.1中改写为不同域外请求。改写不改变L0、C3、
证据空集和行动槽位，记录见
`data/annotations/正式400条域外重复修订记录_v1.1.csv`。

## 数据质量

- 标准化完全重复：0；
- 字符2/3-gram余弦≥0.88的剩余近重复对：0；
- 来源组跨分区泄漏：0；
- 必需/禁止行动严格冲突及复核候选：0；
- 缺失证据ID：0；
- 协议家族或版本链不一致：0；
- 日期和辖区缺失：0；
- 全部质量门槛：通过。

## 使用限制

- 不得使用`test_op/test_ch`调参、选模型或修改标注规则；
- `cal_ch`不得选择确认性主阈值；
- 数据增强只能加入`train`；
- 当前是协议派生和合成开发查询，不支持真实用户有效性结论；
- 地区外结论只对应当前留出的晋城协议家族；
- 权威来源正文的公开再分发受各来源许可限制；
- Windows Smoke和未来Radxa实测必须分开报告。
