# 许可人工核验工作单说明 v0.1

文件：

```text
data/annotations/许可人工核验工作单_v0.1.csv
```

该工作单把15份候选来源拆成逐来源核验字段，供能访问官方页面的环境使用。
当前工作单只是待填表，不会自动把来源升级为正式许可。

## 必填证据

每个来源至少补齐：

1. 官方许可、版权或政府信息再利用政策URL；
2. 页面中的原文摘录；
3. 版本/生效状态的官方证据URL和原文摘录；
4. 若实际下载地址是镜像，补充镜像授权证据；
5. 允许公开的范围和核验日期。

## 结论填写

- `已核验-条件许可`：有明确许可，但附带署名、非商业、相同方式共享或标识限制；
- `已核验-仅元数据`：正文不能再分发，只允许公开来源URL、版本、哈希和证据定位；
- `已核验-可再分发`：有明确允许研究复现包再分发正文或派生文本的依据；
- `仍需核验`：证据不足、页面无法访问或镜像授权关系不清；
- `不纳入`：版本失效、来源不明或适用范围不满足研究协议。
