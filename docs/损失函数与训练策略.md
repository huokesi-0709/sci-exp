# 损失函数与训练策略

## 1. 任务类型

本文模型属于**配置条件多任务预测**。对查询 \(i\) 和候选配置
\(c\in\{C0,C1,C2\}\)，预测：

1. L3 严重失效风险；
2. 必要行动完整率或回答效用；
3. 时延、物理能耗和峰值内存；
4. 是否应进入 C3 以及回退原因。

主任务是严重失效风险预测。其他输出用于提高表示质量、检查资源可行性和解释回退，
不能通过降低辅助损失来交换主任务安全性。

## 2. 训练单位与标签构造

### 2.1 独立统计单位

同一查询在 C0–C2 下的结果，以及同一 query–configuration 的多个生成 seed 和设备
重复运行，不是完全独立样本。数据划分、batch 采样、置信区间和模型选择均以
`source_group_id` 或查询组为单位。

禁止把：

\[
N_{\mathrm{query}}\times3\text{ configurations}\times
3\text{ seeds}
\]

解释为相同数量的独立查询。

### 2.2 严重失效标签

若主安全目标要求配置在预注册生成 seed 集合下均保持安全，可定义查询级稳健标签：

\[
y_{i,c}^{L3}
=
\mathbb I
\left[
\max_{s\in\mathcal S}
y_{i,c,s}^{L3}=1
\right].
\]

即任一预注册生成 seed 发生 L3，该 query–configuration 即标记为失败。这一版本
保守但避免把同一查询的重复 seed 当作独立校准样本。

辅助敏感性分析可使用种子平均失效率：

\[
\bar y_{i,c}^{L3}
=
\frac{1}{|\mathcal S|}
\sum_{s\in\mathcal S}
y_{i,c,s}^{L3}.
\]

必须在实验开始前确定使用“任一 seed 失败”还是“随机 seed 平均风险”作为主风险
定义，不能根据结果选择。

### 2.3 资源与效用标签

- 行动完整率：多标注者裁决后的 \([0,1]\) 分数；
- 时延：同会话重复运行的实测毫秒值；
- 能耗：物理功率积分得到的焦耳；
- 内存：峰值 RSS 或预注册的系统级峰值指标；
- 回退：是否应回退及信息不足、知识冲突、资源不足等多标签原因。

多个设备重复用于估计分位数，不作为独立查询扩大风险训练样本数。

## 3. 主损失

### 3.1 二元交叉熵

严重失效风险头输出：

\[
\widehat p_{i,c}
=
P_\theta(Y_{i,c}^{L3}=1\mid x_i,c).
\]

主损失采用二元交叉熵：

\[
\mathcal L_{\mathrm{BCE}}
=
-\frac{1}{N}
\sum_{i,c}
w_{i,c}
\left[
y_{i,c}\log\widehat p_{i,c}
+(1-y_{i,c})\log(1-\widehat p_{i,c})
\right].
\]

\(w_{i,c}\) 用于查询组权重、有限类别权重和标注置信度，不允许为使测试结果更好而
事后修改。

选择 BCE 的原因：

- 它是概率预测的适当评分规则；
- 比只优化准确率更适合后续风险校准；
- 输出可以按配置排序并在独立校准集确定接受阈值；
- 对逻辑回归和浅层神经网络均适用。

### 3.2 Brier 辅助概率损失

增加较小权重的 Brier loss：

\[
\mathcal L_{\mathrm{Brier}}
=
\frac{1}{N}
\sum_{i,c}
w_{i,c}
(\widehat p_{i,c}-y_{i,c})^2.
\]

Brier loss 直接惩罚概率偏差，减少极端过度自信。但神经网络概率质量改善仍不等于
安全保证，正式安全门必须在独立校准集建立。

### 3.3 主风险损失

\[
\mathcal L_{\mathrm{risk}}
=
\mathcal L_{\mathrm{BCE}}
+\lambda_b\mathcal L_{\mathrm{Brier}}.
\]

建议从：

\[
\lambda_b=0.25
\]

开始，仅在验证集的小范围
\(\{0,0.1,0.25,0.5\}\) 内选择。BCE 始终是主项。

## 4. 辅助损失

### 4.1 行动完整率损失

对裁决后的行动完整率 \(u_{i,c}\in[0,1]\)，使用 Huber loss：

\[
\mathcal L_{\mathrm{utility}}
=
\frac{1}{N_u}
\sum_{i,c}
\operatorname{Huber}
(\widehat u_{i,c}-u_{i,c}).
\]

Huber 对少量标注异常比 MSE 稳健，又比 MAE 更易优化。

### 4.2 时延与能耗分位数损失

资源分布通常右偏，并受热状态和后台负载影响。对
\(\tau\in\{0.50,0.95\}\)，使用 pinball loss：

\[
\rho_\tau(e)
=
\max(\tau e,(\tau-1)e).
\]

时延损失：

\[
\mathcal L_{\mathrm{latency}}
=
\frac{1}{N_L}
\sum_{i,c,\tau}
\rho_\tau
\left[
\log L_{i,c}
-\log\widehat Q_\tau(L_{i,c})
\right].
\]

能耗损失：

\[
\mathcal L_{\mathrm{energy}}
=
\frac{1}{N_E}
\sum_{i,c,\tau}
m_{i,c}^{E}
\rho_\tau
\left[
\log E_{i,c}
-\log\widehat Q_\tau(E_{i,c})
\right],
\]

其中 \(m_{i,c}^{E}=1\) 表示存在可信物理能耗标签，否则为 0。没有功率信号时必须
屏蔽能耗损失，不能用时延、FLOPs、参数量或 token 数伪造焦耳标签。

### 4.3 内存损失

\[
\mathcal L_{\mathrm{memory}}
=
\frac{1}{N_M}
\sum_{i,c}
\operatorname{Huber}
\left[
\log\widehat M_{i,c}-\log M_{i,c}
\right].
\]

### 4.4 回退损失

是否应回退使用二元 BCE：

\[
\mathcal L_{\mathrm{fallback}}
=
\operatorname{BCE}(\widehat p_i^{FB},y_i^{FB}).
\]

回退原因使用多标签 BCE：

\[
\mathcal L_{\mathrm{reason}}
=
\sum_{r\in\mathcal R}
\operatorname{BCE}
(\widehat p_{i,r}^{FB},y_{i,r}^{FB}).
\]

回退头是辅助任务。部署时不能仅凭其 softmax 决定 C3，最终回退还要检查校准风险
集合和资源硬约束。

### 4.5 可选配置排序损失

如果同一查询的多个配置结果均可用，可加入小权重配对排序：

\[
\mathcal L_{\mathrm{rank}}
=
\sum_i
\sum_{(c^+,c^-)}
\max
\left(
0,\,
m-\widehat r_{i,c^-}
+\widehat r_{i,c^+}
\right),
\]

其中 \(c^+\) 表示真实更安全配置，\(c^-\) 表示发生严重失效的配置。

排序损失只用于改善配置相对顺序，建议权重不超过总损失的 5%。若它改善 AUC 但
恶化 Brier、NLL 或校准 coverage，应删除。

## 5. 总损失与权重

总损失：

\[
\begin{aligned}
\mathcal L_{\mathrm{total}}
=\;&
\mathcal L_{\mathrm{risk}}
+\lambda_u\widetilde{\mathcal L}_{\mathrm{utility}}
+\lambda_L\widetilde{\mathcal L}_{\mathrm{latency}}\\
&+\lambda_E\widetilde{\mathcal L}_{\mathrm{energy}}
+\lambda_M\widetilde{\mathcal L}_{\mathrm{memory}}
+\lambda_f\widetilde{\mathcal L}_{\mathrm{fallback}}\\
&+\lambda_{fr}\widetilde{\mathcal L}_{\mathrm{reason}}
+\lambda_r\widetilde{\mathcal L}_{\mathrm{rank}}
+\lambda_2\|\theta\|_2^2.
\end{aligned}
\]

辅助损失先按训练集尺度标准化，使初始数量级相近。可使用的起始权重为：

| 损失 | 起始权重 |
| --- | ---: |
| 风险 BCE | 1.00 |
| Brier | 0.25 |
| 行动完整率 | 0.20 |
| 时延分位数 | 0.10 |
| 能耗分位数 | 0.10 |
| 内存 | 0.05 |
| 是否回退 | 0.10 |
| 回退原因 | 0.05 |
| 配置排序 | 0 或 0.05 |

这些数值是验证集搜索的起点，不是预先知道的最优值。搜索时应限制在小范围，避免
当前小数据下为多任务权重进行大规模过拟合。

不推荐在主实验中使用自动 uncertainty weighting 或复杂梯度平衡算法，因为它们会
增加自由度，可能在小样本下把主风险任务权重自动降低。

## 6. 类别不平衡处理

L3 可能只有约 1%–10%，应采用以下顺序处理。

### 6.1 保持自然分布

验证、校准和测试集必须保持真实或预注册抽样分布。不能为得到更好指标而在评估阶段
过采样严重错误。

### 6.2 查询组级分层 batch

训练 batch 以查询组为单位采样，一个查询对应的 C0–C2 记录保持相同组权重。可以
提高包含 L3 正例查询的 batch 出现概率，但同一查询的多配置和重复 seed 总权重不能
超过一个查询组的预注册权重。

### 6.3 有限正类权重

训练集正类权重可设为：

\[
w_+
=
\min
\left(
w_{\max},
\sqrt{\frac{N_-}{N_+}}
\right),
\]

建议：

\[
w_{\max}\in\{3,5\}.
\]

使用平方根和上限，避免极少数正例产生过大梯度。不同权重只在 valid 比较。

类别加权会改变概率的自然基率，因此无论是否加权，最终都必须独立校准。

### 6.4 不推荐 SMOTE

不建议在文本 embedding 与设备特征拼接空间直接使用 SMOTE。人工插值可能产生
不存在的应急语义和设备状态组合，并模糊协议严重失效边界。

### 6.5 Focal loss 仅作消融

Focal loss 可提高困难正例权重，但可能损害概率校准。仅作为辅助实验：

\[
\gamma\in\{1,2\}.
\]

若使用，必须与 BCE 在相同独立校准流程下比较 risk–coverage、Brier 和 NLL，不能
只比较 F1 或 AUROC。

### 6.6 指标选择

类别不平衡时重点报告：

- L3 风险和精确上界；
- PR-AUC；
- L3 recall；
- Brier/NLL；
- risk@coverage；
- 每灾种和挑战子组风险。

准确率和 AUROC 只能作为补充。

## 7. 正则化策略

### 7.1 参数正则化

- 文本编码器默认冻结；
- 可训练层使用 AdamW weight decay，起点 \(10^{-4}\)；
- Dropout 从 \(\{0.05,0.10,0.20\}\) 在 valid 选择；
- 隐藏层不超过 2–3 层；
- 梯度全局范数裁剪为 1.0。

### 7.2 特征正则化

- 连续变量按 train 统计量标准化和截尾；
- 所有可缺失变量增加 missing indicator；
- 训练时以小概率屏蔽知识或设备特征组；
- 对传感器数值加入不超过已验证测量误差的小扰动；
- 不对风险等级、协议状态或 L3 标签做随意随机增强。

特征组 dropout 建议从：

\[
p_{\mathrm{group}}\in\{0,0.05,0.10\}
\]

选择。其目标是增强遥测缺失稳健性，不是让模型忽略关键安全输入。

### 7.3 数据增强边界

同义改写、错别字和信息删除增强只能在 train 内产生，并继承原
`source_group_id`。增强样本不能跨 valid/calibration/test，也不能在看到测试错误后
针对性生成。

删除地点、对象或时间可能改变正确标签，必须重新人工判定，不能自动继承原标签。

### 7.4 标签噪声

主实验使用裁决后的二元 L3 标签。标注者分歧比例用于：

- 样本质量审查；
- 软标签敏感性分析；
- 高分歧子组报告。

不建议静默删除所有分歧样本，否则测试集会变得不现实地简单。

## 8. 优化器与学习率计划

### 8.1 标准 AI+ 模型

冻结文本编码器、训练浅层融合网络时建议：

| 项目 | 建议起点 |
| --- | --- |
| 优化器 | AdamW |
| 主干/输出头初始学习率 | \(1\times10^{-3}\) |
| weight decay | \(1\times10^{-4}\) |
| query-group batch | 16–32 个独立查询 |
| 梯度裁剪 | 1.0 |
| 最大 epoch | 100–150 |
| warmup | 总 optimizer steps 的 5% |
| 最低学习率 | \(1\times10^{-5}\) |

学习率计划：

1. 前 5% optimizer steps 线性 warmup；
2. 其余步骤使用 cosine decay；
3. 不在 calibration/test 上重启学习率或继续训练。

### 8.2 部分微调文本编码器

当前数据规模不默认启用。只有冻结模型明确语义欠拟合时，才进行辅助实验：

- 编码器学习率：\(1\times10^{-5}\) 或更低；
- 主干/输出头学习率：\(3\times10^{-4}\) 至 \(1\times10^{-3}\)；
- 先只训练输出头 3–5 epoch；
- 再解冻最后 1–2 层；
- 更短 patience 和更强 weight decay；
- 必须进行多 seed 和简单模型对照。

### 8.3 简单逻辑回归

如果采用第一档可解释方案，优先使用稳定的凸优化求解器和 L1/L2 正则化，不需要
人为设置神经网络式学习率计划。正则强度只在 valid 的小网格中选择。

## 9. 早停机制

### 9.1 监控集合

早停只能监控 `valid`。`cal_op` 只用于冻结模型后的风险阈值，`test_op/test_ch`
不能用于早停。

### 9.2 监控分数

建议定义验证综合损失：

\[
\begin{aligned}
S_{\mathrm{valid}}
=\;&
\operatorname{NLL}_{L3}
+0.5\operatorname{Brier}_{L3}\\
&+0.2\operatorname{Huber}_{U}
+0.1\operatorname{Pinball}_{L,0.95}\\
&+0.1\operatorname{Pinball}_{E,0.95},
\end{aligned}
\]

其中能耗不可用时删除对应项并重新归一化权重。综合分数中安全概率质量占主要权重。

同时设置安全护栏：

- validation L3 PR-AUC 不得持续下降；
- 最坏灾种 L3 recall 不得低于预注册下限；
- 出现 NaN、概率塌缩或只预测单一类别时立即标记训练失败。

### 9.3 早停参数

- 前 10 epoch 作为最短训练期；
- patience 建议 10–15 个 epoch；
- 相对改善小于 \(10^{-3}\) 视为无实质改善；
- 保存 \(S_{\mathrm{valid}}\) 最小 checkpoint；
- 训练结束恢复最佳 checkpoint，而不是最后一个 checkpoint。

若 valid 中 L3 正例太少，单 epoch 指标波动较大，应使用 3 个 epoch 的移动平均，
并通过 group bootstrap 检查候选 checkpoint 差异，而不是缩短 patience。

## 10. 模型选择标准

### 10.1 同一架构内的 checkpoint

每个 train seed 自动选择：

\[
\theta_s^\star
=
\arg\min_\theta S_{\mathrm{valid}}(\theta).
\]

不能人工查看 test 后挑选 epoch。

### 10.2 架构与超参数选择

采用字典序标准：

1. validation 风险概率质量达到预注册要求；
2. L3 PR-AUC、recall 和最坏子组风险无明显退化；
3. 在前两项近似相当时，行动完整率更高；
4. 再比较 P95 时延和能耗预测误差；
5. 若性能处于一个标准误以内，选择参数更少、路由开销更低、解释更清楚的模型。

可表述为：

> 在验证风险表现不劣于最佳模型一个标准误的候选中，选择 Radxa 实测路由开销最低
> 的模型。

### 10.3 多随机种子

建议训练种子：

\[
\{11,23,37,51,71\}.
\]

论文报告所有 seed 的均值、区间和失败训练。正式部署模型按照预注册 valid 规则选择，
不得选择测试表现最好的 seed。

如果 seed ensemble 的风险收益不能覆盖其多倍设备开销，则不部署 ensemble。

### 10.4 独立校准不是模型选择

模型和超参数完全冻结后，才在 `cal_op` 选择配置级接受阈值。不得：

- 根据 calibration coverage 返回修改网络；
- 选择在 calibration 上表现最好的 seed；
- 根据 test 风险调整 \(\alpha,\delta\)；
- 删除校准中难以接受的灾种。

`cal_ch` 只评价偏移下保证退化，不重新选择主模型。

## 11. 推荐训练流程

```text
输入：
    train、valid、cal_op、cal_ch、test_op、test_ch
    预注册 train seeds
    冻结文本编码器

1  仅用 train 拟合标准化、缺失填补和类别权重
2  按 query/source_group 组成 batch
3  对每个 train seed：
4      初始化浅层融合网络与多任务头
5      用 AdamW + warmup + cosine decay 训练
6      监控 valid 综合分数和安全护栏
7      触发早停后恢复该 seed 的最佳 checkpoint
8  按预注册 valid 规则冻结架构、超参数和部署 checkpoint
9  在 cal_op 产生风险分数并选择安全阈值
10 在 cal_ch 检查偏移，不修改模型和阈值
11 仅运行一次 test_op/test_ch 最终评价
12 在 Radxa 上报告模型预测开销、净节能和热态稳定性
```

## 12. 推荐的最小消融

为验证损失和训练策略，应至少比较：

| 消融 | 目的 |
| --- | --- |
| BCE only | 检查 Brier 辅助项是否必要 |
| BCE + Brier | 主风险损失 |
| 不使用类别权重 | 检查权重对概率和 recall 的影响 |
| Focal loss | 检查分类改善是否损害校准 |
| 不使用辅助任务 | 检查多任务是否真正改善主风险 |
| 不使用资源分位数 | 比较平均资源预测与尾部约束 |
| 不使用特征组 dropout | 检查遥测缺失稳健性 |
| 单 seed vs 多 seed | 量化训练不稳定性 |

所有版本必须重新在相同 `cal_op` 规则下校准，不能共用某一模型的阈值。

## 13. 当前研究的最终建议

当前数据规模下，优先使用：

\[
\boxed{
\mathcal L_{\mathrm{BCE}}
+0.25\mathcal L_{\mathrm{Brier}}
+\text{小权重效用与资源辅助损失}
}
\]

并配合：

- query-group 分层 batch；
- 上限为 3–5 的有限正类权重；
- 冻结文本编码器；
- AdamW、5% warmup 和 cosine decay；
- Dropout、L2、特征组屏蔽与梯度裁剪；
- valid 综合分数早停；
- 五个训练 seed；
- 模型冻结后的独立风险校准；
- 一个标准误规则优先选择简单、低开销模型。

若多任务模型没有稳定改善主风险、行动完整率或 Radxa 净资源收益，应回退到
TF-IDF/BM25 + 正则化逻辑回归，而不是继续增加模型复杂度。
