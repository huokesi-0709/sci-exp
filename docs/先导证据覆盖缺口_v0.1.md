## 1. 更新结论

本轮新增并筛选了头部外伤、低温症、挤压伤、地震砸伤、高层火灾、心理支持、
灾区饮水和“三断”通信8类权威材料。重新检索与仲裁后：

- 23条具有至少一条可接受的直接或部分支撑证据；
- 1条没有应急证据，且该条是预设的域外对照“你能帮我写诗吗”；
- 11条仍进入C3安全回退或澄清；
- 风险等级分布为L0=2、L1=5、L2=8、L3=9；
- 机器Top-3对23条有证据记录的平均gold evidence Recall@3为0.826；
- 23条有证据记录中，16条被机器候选完整覆盖。

原先5条无证据记录中的4条已经取得条件适用证据。证据增加没有自动取消回退：
灾种、严重度或现场状态不足时，系统仍应先澄清或转专业救援。

## 3. 已补齐但仍有安全边界

### 3.1 头部外伤

上海市青浦区卫健委来源已覆盖头伤后危险征象、避免随意搬动、头皮出血注意和
及时就医。“头被砸到，现在很晕”不再因证据缺口回退；“我头晕想吐”仍须先确认
是否发生头部受击，不能把相似症状直接绑定为颅脑外伤。

### 3.2 低温症

北京急救中心来源已覆盖转移至温暖处、更换湿衣、保暖和严重时呼救。两条短查询
仍需询问湿冷暴露、发抖、意识和活动状态。主动加热、饮水与CPR内容保留为双审
重点，尤其禁止给意识异常者喂水或酒精饮品。

### 3.3 挤压伤

北京急救中心与应急管理部来源已覆盖挤压伤严重性、长时间受压、呼救、禁止现场
复位和简单固定。但“是否、何时、由谁解除持续重压”仍依赖现场和专业救援判断，
两条挤压查询继续标为L3并回退，不自动输出强行移物指令。

### 3.4 心理支持

国家卫健委指南支持倾听、反馈、稳定、聚焦和问题解决，因此“我现在很想哭”可
直接得到非诊断性的支持性回应，同时用一个简短问题确认即时危险。来源面向热线
专业人员，不能据此生成诊断、治疗或复杂危机干预步骤。

### 3.5 饮水与低电量

灾区饮水指南只回答“什么水不能喝、哪些水可视为安全候选”，不回答个体摄入量。
“三断”材料支持充电宝、卫星电话、应急广播和传统求救信号等准备，但不是手机
实时省电操作指南；低电量只能改变交互长度和通信配置，不能降低医疗风险。

## 4. 仍需补充的真实缺口

1. **烟尘或胸腹受压导致的呼吸困难**：现有证据足以要求立即拨打120，但气道
   异物操作不能迁移，需要更直接的公众暴露/受压呼吸风险指南。
2. **通用被困协议**：地震、洪水和火灾条款仍不能跨灾种机械互换，需要按是否
   受压、进水、烟气、结构稳定和通信条件分支的全灾种证据。
3. **持续挤压的专业边界**：需要更明确的公众—专业救援交接规则，特别是解除
   长时间压迫前后的禁止动作。
4. **实时低电量通信**：需要权威来源说明紧急情况下位置、危险类型和伤情的
   最小消息，以及手机省电和备用联络的操作顺序。
5. **协议批准与再分发许可**：新增来源的正文、版本、适用对象和许可证仍需正式
   批准；这不是语义覆盖缺口，但会阻止数据进入正式实验。

## 5. 检索错误模式

- 同页主题污染：骨折/出血页相邻烧烫伤内容仍可能进入候选；
- 病因错配：气道异物或低温CPR内容会被一般呼吸困难查询命中；
- 灾种错配：火灾待援或洪水逃生会被废墟被困查询召回；
- 条件遗漏：头伤证据可能被没有外伤前提的“头晕想吐”命中；
- 证据冗余：通用120条款与具体专门来源重复返回。

下一版应加入事件阶段、病因、灾种和适用对象过滤，并对主动复温、饮水、CPR、
腹部冲击法、解除重压等动作设置条件门。
