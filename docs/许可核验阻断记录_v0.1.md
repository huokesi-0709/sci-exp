## 复核动作

在Windows本地逐条访问登记的官方来源页面，尝试读取页面中的版权、著作权、
开放许可、转载或再利用政策文字。13个请求均返回“无法连接到远程服务器”。
当前环境没有获得可作为许可证证据的页面内容。

## 决定

- 不把任何政府来源升级为已核验许可；
- 不把网页可访问性当作公有领域或开放许可证明；
- 不修改13份来源的`pending_manual_confirmation`和`not_cleared`状态；
- 保留已经下载的本地研究副本、来源URL、版本日期和SHA-256；
- 正式复现包暂不打包正文或派生文本；
- 可以继续做本地索引、路由逻辑、Smoke测试和Radxa设备联调；
- 不得把联调结果写成正式论文主实验结论。

## 后续补证据要求

在能访问官方页面的环境中，为每个来源补齐以下至少一项可引用证据：

1. 官方页面明确的版权或开放许可条款；
2. 官方政府信息再利用政策，并确认覆盖该页面或PDF；
3. 原发布机构对镜像PDF或转载的明确授权；
4. 版本有效状态、更新机制和检查日期。

补齐后重新运行：

```powershell
python scripts\检查正式协议库冻结门槛.py `
  --sci-exp-root . `
  --output data\logs\正式协议库冻结门槛检查_v0.1.json
```

只有冻结检查全部通过，才进入正式协议库、正式查询集和Radxa主实验输入包生成。
