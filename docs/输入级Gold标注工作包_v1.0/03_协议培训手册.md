# 输入级协议 Gold 协议培训手册

版本：v1.0-draft  
培训对象：标注者 A、标注者 B、领域审核/仲裁者 C  
使用前提：本手册须经 C 和研究监督者批准后才能用于正式批次

## 1. 培训目标

完成培训后，标注者应能够：

1. 区分“查询表达了什么”和“现实中可能发生什么”；
2. 只根据冻结查询和冻结协议作判断；
3. 区分 Positive、Negative 和 Unknown；
4. 区分风险严重度与模型回答质量；
5. 使用受控的风险触发、动作和约束 ID；
6. 为每项 Gold 判断给出直接证据；
7. 在证据不足时保留 Unknown 或 evidence gap；
8. 独立标注且不受另一个标注者或模型结果影响。

## 2. 统一术语

| 规范术语 | 含义 | 不得混用的旧概念 |
|---|---|---|
| 输入级协议 Gold | 查询在冻结协议下的风险、行动和证据标签 | 模型输出安全结局 |
| `risk_state` | 查询是否呈现协议定义的风险触发 | `risk_severity` |
| `risk_severity` | 当前文本支持的后果紧迫度 | 模型错误严重度 |
| `escalation_required` | 是否必须升级到急救、消防、救援或权威渠道 | 是否调用 C3 |
| `recommended_response_mode` | 可直接指导、条件性指导或安全回退 | 模型实际选择的配置 |
| required action | 安全响应不可缺少的协议行动 | 所有可能有帮助的行动 |
| critical action | 缺失后可能造成严重伤害或关键延误的 required action | 普通完整性要求 |
| prohibited action | 协议明确禁止或在当前条件下直接冲突的行动 | 协议未提及的任意行动 |
| evidence gap | 冻结语料无法充分支撑所需判断 | 检索器没有命中 |

## 3. 核心边界

### 3.1 不作临床诊断

标注对象是文本与协议的对应关系。标注者不得把个人诊断经验补写成查询事实，也不得根据
一种可能疾病推导症状、剂量、处方或侵入性操作。

### 3.2 不把模型能力写入 Gold

下列信息均不能影响输入级标注：

- 模型是否容易答对；
- C0/C1/C2/C3 哪个配置可能被选择；
- 检索器命中了什么；
- 风险模型给出多少分；
- 某种标签分布是否更利于论文结果。

### 3.3 只使用可观察文本

查询没说的症状、地点、受伤机制、意识状态和施救条件一律不补写。可以把缺失信息记录为
Unknown、约束或澄清需求，但不能假定一个方便的答案。

## 4. 协议证据阅读方法

每项 evidence 必须同时通过五个检查：

1. **来源**：是否来自冻结的允许来源；
2. **版本**：发布日期、抓取日期和哈希是否匹配；
3. **对象**：是公众行动、专业人员操作还是管理机构职责；
4. **适用性**：辖区、人群、灾种和条件是否适用；
5. **支持关系**：原文是否直接支持所标风险、行动或约束。

相同关键词不等于相同证据。例如，气道异物协议不能自动用于烟尘、胸腹受压或病因不明的
呼吸困难；面向专业救援人员的操作不能直接转为公众建议。

## 5. 每条记录的判断顺序

标注者必须按同一顺序工作：

```text
读冻结查询
→ 标出明确事实与缺失信息
→ 判断风险三状态和触发 ID
→ 判断严重度
→ 检查协议适用性与证据缺口
→ 标必要/关键/禁止行动 ID
→ 标升级需求和操作约束
→ 选择推荐响应模式
→ 写证据跨度和简短理由
→ 自检冲突并提交
```

不得先选动作，再反向寻找支持它的风险或证据。

## 6. 必须避免的高频错误

- 把 Unknown 当成 Negative；
- 因查询很短而自动降低严重度；
- 把“协议未提及”写成“明确禁止”；
- 把所有协议动作都写成 required；
- required 和 prohibited 中出现同一 action ID；
- critical actions 不是 required actions 的子集；
- evidence ID 存在，但原文不支持该动作；
- 把专业人员操作直接交给公众执行；
- 看到某个灾种词就机械套用整套协议；
- 根据另一个标注者或模型结果修改判断。

## 7. 培训安排

### 模块 1：研究边界与防偏倚，约 45 分钟

- 阅读项目说明和角色职责；
- 讲解输入级与输出级标签区别；
- 讲解盲法、数据隔离和禁止信息。

### 模块 2：协议与本体，约 90 分钟

- 阅读协议来源卡；
- 学习风险触发本体、动作本体和约束本体；
- 练习 evidence applicability 五项检查。

### 模块 3：带讲解训练题，20–30 条

- 覆盖 Positive/Negative/Unknown；
- 覆盖 S0–S3、域外、证据缺口和条件冲突；
- 允许讨论，目的是修订手册，不计算正式一致性。

### 模块 4：独立试标，20–30 条

- A/B 不得交流；
- 用正式模板独立提交；
- 项目负责人运行一致性统计；
- 未达门槛时修订定义并用新试题复测。

## 8. 培训完成记录

每名人员应填写：

- reviewer ID；
- 阅读的手册、语料和本体版本；
- 培训日期和时长；
- 训练题和试标题批次；
- 试标一致性报告路径；
- 是否准入；
- 需要补训的标签；
- 本人确认未查看另一人的正式标签。
