# 输入级协议 Gold 标注工作包 v1.0

状态：`draft_for_domain_review`  
创建日期：2026-08-21  
适用项目：SC-EA-RAG  
适用范围：输入级协议 Gold，不包含模型输出级标注

## 1. 工作包边界

本工作包用于建立可审计的输入级协议 Gold。它回答的是：给定一条公众应急查询，冻结的
权威协议是否支持某类风险判断、必要行动、禁止行动、升级需求、约束和证据跨度。

它不用于临床诊断、治疗建议有效性评价、真实患者分诊或“系统已经获得医学安全认证”的
主张。所有正式结论均应表述为与指定协议语料的一致性或 protocol-grounded safety。

当前 400 条数据继续保持 `development_gold`，不得因本工作包存在而自动升级为 Gold
Calibration 或 Gold Test。本工作包中的门槛在领域审核者签字确认前均为项目内部候选门槛。

## 2. 使用顺序

1. 阅读 [项目说明书](00_项目说明书.md)。
2. 确认 [人员角色与职责](01_人员角色与职责.md)，分配 A、B 和 C。
3. 使用 [专业人员招募与合作说明](02_专业人员招募与合作说明.md) 联系领域人员。
4. 领域审核者检查 [协议培训手册](03_协议培训手册.md) 和
   [输入级 Gold 标注手册](04_输入级Gold标注手册.md)。
5. 按 [试标与准入 SOP](05_试标与准入SOP.md) 完成两轮独立试标。
6. 按 [正式双盲标注 SOP](06_正式双盲标注SOP.md) 生成独立 A/B 原始文件。
7. 项目负责人按 [一致性计算 SOP](07_一致性计算与质量门禁SOP.md) 运行统计脚本。
8. 领域仲裁者按 [仲裁与冻结 SOP](08_分歧仲裁与冻结SOP.md) 处理分歧。
9. 使用 [论文报告模板](09_论文Methods与Results报告模板.md) 编写论文。
10. 每批次执行 [检查清单](10_执行检查清单.md)。
11. 按 [人员身份推荐与准入要求](11_人员身份推荐与准入要求_v1.1.md) 核验 A/B/C。
12. 阅读 [标签体系与质量门槛审核](12_标签体系与质量门槛审核_v1.1.md)，不得跳过阻断项。
13. 主持人按 [主持人与 ABC 现场执行指南](13_主持人与ABC现场执行指南_v1.1.md) 发放和回收。
14. 题目来源和互斥规则见 [培训与独立试标题抽样方案](14_培训与独立试标题抽样方案_v1.1.md)。

## 3. 数据目录

人工标注文件统一放在：

```text
data/annotations/input_gold_v1.0/
├── templates/             # 空白表、人员登记表、动作/触发本体模板
├── schemas/               # 原始标注与仲裁 JSON Schema
├── pilot/                 # 培训和试标数据，不进入正式 Gold
├── formal/reviewer_A/     # A 的原始正式标注，只写不覆盖
├── formal/reviewer_B/     # B 的原始正式标注，只写不覆盖
├── adjudication/          # C 的逐项仲裁结果
├── reports/               # 一致性、质控、哈希和异常报告
└── frozen/                # 完成全部门禁后生成的只读冻结快照
```

`data/annotations/` 已在 `.radxa-sync-exclude` 中排除，不得把 A/B、仲裁或 Gold 文件同步到
推理设备。Radxa 只接收 Gold-free 的 `InferenceQuery` 视图。

## 4. 一句话责任链

```text
负责人冻结材料 → A/B 独立盲标 → 负责人计算仲裁前一致性
→ C 按证据仲裁 → 负责人执行质量门禁和哈希冻结 → 导师批准实验用途
```

## 5. 当前不可填写为“已完成”的项目

- 领域审核者姓名、资格和审核日期；
- 伦理审查、豁免或不适用认定；
- 正式标注员培训结果；
- 真实 A/B 一致性；
- 正式 Gold Calibration/Test 样本量和分区；
- 领域审核者签字确认的动作本体、严重度和质量门槛。

## 6. v1.1 方法学审核结论

- 人员配置和独立双盲流程可以实施；
- 严重度和响应模式经补充操作定义后可提交 C 复核；
- 现有三套本体文件只有占位行，尚未达到可冻结状态；
- 旧 `development_gold` 中发现跨场景动作错配，旧答案不得作为培训答案；
- 质量门槛已完成方法学条件批准，但在 C、S、T 真实签字前不视为正式批准。
