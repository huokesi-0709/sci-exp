# 培训题与独立试标题抽样方案

版本：v1.1  
来源：`正式400条分层冻结_v2.0.jsonl` 中的题干  
数据用途：仅 TRAINING/PILOT，`formal_evidence=false`

## 1. 数量和互斥规则

- 培训练习：25 条；
- 独立试标：25 条；
- 每个集合每个 `source_group_id` 最多取 1 条；
- 两集合 query ID 和 source group 完全不重叠；
- A/B 看到的是盲化 item ID 和盲化 group ID，主持人单独保管映射；
- 两集合均永久排除于后续正式 Gold calibration/test。

## 2. 培训练习覆盖

培训集优先覆盖典型例和需要讲清定义的边界：心搏骤停/无正常呼吸、完全窒息、出血、骨折、
烧伤、失温、中毒、火灾、洪水、雷电、头部外伤、心理支持、天气预警、资源不足、低电量、
域外、建筑安全不明、水质不明、落水后有呼吸和触电后清醒等。

培训题没有自动继承旧答案。C 必须先用冻结协议建立参考答案；A/B 首次作答后，才可展示
C 答案并讨论。

## 3. 独立试标覆盖

试标集侧重高风险和难分支：中毒昏迷、溺水无反应、触电无反应、头伤昏迷、严重失温、烟雾
呼吸衰竭、挤压休克、坍塌呼吸受限、头伤反复呕吐、火场被困、严重出血合并头伤，以及
撤离路线不明、出口烟火方向不明、心理支持、热暴露、三断、域外和资源复合场景。

## 4. 为什么不直接使用旧答案

抽样复核已经发现旧 action 标签的跨场景错配和非原子化问题。旧字段仅用于覆盖抽样，不能
作为 C 的参考标准，更不能发给 A/B。培训答案的产生路径必须是：

```text
冻结题干 + 冻结协议 + 经审核本体 → C 逐题填写参考答案 → 主持人锁定
```

## 5. 生成物

四份工作簿分别面向 A、B、C 和主持人。A/B 的题序不同，但 blind item ID 集合一致；C 包含
培训参考答案和仲裁表；主持人包包含真实 query/source-group 映射、发放回收清单和门槛。

生成后必须运行自动检查，至少证明：25/25 数量正确、query 和 source group 零重叠、全部
题干来自开发材料、A/B 试标 ID 集合一致、A/B 不含旧标签列。
