# A/B/C 人员身份推荐与准入要求

版本：v1.1  
状态：方法学建议，人员身份待真实登记

## 1. 最推荐的现实配置

考虑到项目负责人是计算机专业研究者，推荐采用以下配置：

| 角色 | 最推荐身份 | 最低可接受配置 | 为什么 |
|---|---|---|---|
| A | 项目负责人或熟悉数据规范的计算机研究者 | 完成协议培训和准入试标的研究人员 | A 负责严格按冻结协议做可复现的数据判断，不冒充临床专家 |
| B | 持有效救护员证/应急救护师资证的人员、急诊/院前/护理人员或急救培训教师 | 与 A 独立、完成培训，且有可核验急救训练经历的人员 | 让至少一名一线领域人员直接参与全部样本，而不只处理少数分歧 |
| C | 急诊医学、院前急救、急诊/重症护理或红十字应急救护培训的资深人员 | 能核验资历、熟悉公众急救边界、未参与 A/B 正式盲标的人 | C 负责本体、严重度、升级边界和分歧的最终领域判断 |

如果资源允许，最佳配置是 A、B 均具备相关专业训练，C 比 A/B 具有更高的领域资历且独立。
如果只能找到一名专业人员，不要让其同时承担 B 和 C：优先让专业人员担任 C，A/B 为两名
经训练的独立标注者；但此配置应在论文中写成“trained raters with domain adjudication”，不能
写成“two clinical experts”。

## 2. C 的优选要求

C 的资历按优先级排序：

1. 急诊或院前急救执业医师；
2. 急诊、重症或院前急救注册护士；
3. 经机构认证的红十字应急救护师资或长期承担公众急救培训的专业人员；
4. 灾害医学、应急救援中负责医疗救护规范培训的人员。

优选条件而非虚构的硬门槛：具有 3 年以上相关实践或教学经验；能说明执业/培训证书编号或
由所在机构核验；熟悉公众可执行操作与专业操作的边界；愿意依据冻结协议而非只凭个人经验
作出书面判断。

不推荐：仅因“是一般医学专业”但不熟悉急救的人员；无法核验身份的网络志愿者；负责论文
结果且会因期望结果修改标签的人；只愿口头给结论、不记录证据的人。

## 3. A/B 的共同准入要求

A/B 不要求具有完全相同的学历，但必须满足：

- 18 岁以上并签署保密、利益冲突和独立标注声明；
- 能逐字阅读中文协议材料；
- 完成培训题，理解 scope、risk、severity、escalation、response mode、evidence、action 和
  constraint 的区别；
- 独立试标期间不讨论个案、不查看旧开发标签或模型输出；
- 能按受控 ID 填表，不自行创造标签；
- 通过冻结的准入门槛或被明确限制只能标部分字段。

## 4. 身份核验材料

主持人只登记完成研究所需的最少信息：匿名 reviewer ID、职业类别、最高相关资质、相关年限、
培训完成日期、利益冲突、可标字段和签字日期。证件扫描件若非机构要求，不放入论文数据包，
仅由负责人加密保存或由导师现场核验并记录“已核验”。

## 5. 冲突和兼任规则

- A 与 B 不能是同一人，不能互看答案；
- C 最好不兼任 A 或 B；只有一名领域人员时，宁可让 C 独立于 A/B；
- 项目负责人可以担任 A，也可以只担任主持人，但不能替 B 填写；
- 导师可兼任研究监督者 S 和统计复核者 T，但不能根据期望实验结果改 Gold；
- 任何人在正式标注前已看过旧答案，应更换题目或登记为非盲，并不得计入独立一致性。

## 6. 公开依据和论文表述边界

中国红十字会公开的救护师资招募/培训材料把医学或教育相关背景、已取得救护员证书等作为
重要条件；国家卫健委的院前医疗急救培训标准则针对持执业资格的医护人员。二者对应不同
层级，不能把救护员证书等同于执业医师资格。

论文应逐项报告 A/B/C 的人数、训练背景、相关经验、是否独立、盲法、试标样本和仲裁方式，
不得只写“由专家双审”。
