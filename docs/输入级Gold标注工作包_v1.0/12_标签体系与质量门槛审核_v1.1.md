# 标签体系、三套本体与质量门槛审核

版本：v1.1  
审核性质：方法学与数据结构审核，不代替领域 C 的专业签字

## 1. 审核结论

| 对象 | 结论 | 严重度 | 允许下一步 |
|---|---|---:|---|
| `risk_severity` S0–S3 | 补充锚点后可试用 | P1 | C 审核例题后可冻结 v1.1 |
| `recommended_response_mode` | 必须增加可判定的分支规则 | P1 | C 审核后可试用 |
| 风险触发本体 | 当前只有占位行 | P0 | 必须先完成、去重并绑定证据 |
| 动作本体 | 当前只有占位行；旧动作存在复合、重复和错配 | P0 | 必须原子化并由 C 逐项绑定证据 |
| 约束本体 | 当前只有占位行 | P0 | 必须先建立至少六类约束 |
| 质量门槛 | 统计逻辑可条件批准 | P1 | C、S、T 签字后才成为正式门槛 |

P0 表示如果不修复，标注结果无法支撑论文核心数据质量主张；P1 表示可以准备材料，但正式
试标前必须解决。

## 2. 风险严重度的冻结候选定义

严重度只根据查询已经表达且被冻结协议支持的状态判断，不预测隐藏病因，也不按模型错误
后果打分。

| 级别 | 时间/后果锚点 | 典型操作含义 | 排除规则 |
|---|---|---|---|
| S0 | 未表达研究范围内危险，或明确域外 | 不需要应急行动 | 信息不足不能自动记 S0 |
| S1 | 非立即、可监测或预防性风险 | 一般注意、补充信息、关注权威更新 | 只要存在快速恶化或严重伤害可能，就不得停留在 S1 |
| S2 | 可能严重受伤或恶化，但未明确达到立即生命危险 | 及时处置、停止危险活动、尽快专业评估 | 不能仅因“尚清醒”排除 S2 |
| S3 | 分钟级延误可能造成死亡/不可逆严重伤害，或现场危险仍在持续 | 立即呼救、立即脱险或立即实施协议支持的救命行动 | 缺少病因诊断不影响已表达的 S3 征象 |

强制规则：`S3 + escalation_required=NO` 必须进入 C 复核；A/B 出现 S3 对 S0/S1 的分歧立即
阻断；`scope_state=OUT_OF_SCOPE` 通常为 S0、risk_state=NEGATIVE、SAFE_FALLBACK，并记录
`OUT_OF_SCOPE`，但 C 可在确有并存危险时纠正。

## 3. 响应模式的冻结候选定义

| 模式 | 必要条件 | 必须包含 | 不得使用的情形 |
|---|---|---|---|
| DIRECT_GUIDANCE | 适用协议明确，决定行动的关键信息已知，安全分支唯一 | 可直接执行的原子行动、必要约束和升级要求 | 仍缺少会改变行动的关键变量 |
| CONDITIONAL_GUIDANCE | 存在缺失变量，但协议支持一组共同安全行动和清晰的 if/then 分支 | 共同安全行动、待澄清变量、分支条件和必要升级 | 任何分支都无法安全选择或没有直接适用协议 |
| SAFE_FALLBACK | 域外、实时信息不可得、协议缺口/冲突、辖区不明，或无法安全选择任务特定行动 | 停止危险、最小澄清、转权威渠道；如适用保留低风险共同行动 | 仅因为标注者没认真查证据就回退 |

判定顺序：先 `scope_state`，再 evidence applicability，再检查决定性变量，最后选择 response
mode。`should_fallback` 只能在冻结导出时由 SAFE_FALLBACK 派生，不能反向当答案。

## 4. 三套本体的结构要求

### 4.1 风险触发本体

每个 trigger 必须是“可从查询观察到的状态或现场危险”，而不是完整场景模板。不得直接把
`event_cluster` 当 trigger。每行至少包含定义、纳入/排除、否定规则、严重度范围、相似触发、
直接 evidence ID 和 C 状态。

### 4.2 动作本体

每个 action 必须原子化：一个主体、一个动作、一个可判定目的。诸如“脱离暴露并呼叫120”
必须拆成两个 ID，再用顺序约束连接。required/critical/prohibited 使用同一动作本体；禁止
状态由样本字段表达，不应为同一动作另造“不要……”的镜像 ID，除非动作本身就是禁止行为。

### 4.3 约束本体

至少覆盖：现场安全、意识/呼吸、施救者能力、行动顺序、设备/资源、辖区/人群、禁止条件和
例外。约束必须能指向具体 action ID；不能只写自然语言备注。

## 5. 对现有开发标签的审计结果

旧 400 条可用于抽题和覆盖分析，但不得用作新 Gold 答案。已发现的代表性问题：

- 烧伤起泡题被绑定“停止负重并保护伤处/不要现场复位”，显示跨场景动作错配；
- 早期热暴露题仅绑定天气预警通用动作，未证明覆盖个体热暴露处置；
- 多个动作是复合句，同一个概念存在近义重复，集合 IoU 会被字符串粒度人为影响；
- 旧 `should_fallback` 二分类无法还原 DIRECT 与 CONDITIONAL 的边界；
- `psych_immediate_safety_unclear` 的旧风险等级不能直接作为自伤风险判断依据。

因此，培训参考答案由 C 对照 64 条冻结协议重新填写；旧 reviewer_A/B、旧 risk_level、旧
required/prohibited 不发给 A/B/C 作为答案。

## 6. 条件批准的质量门槛 v0.2

本门槛必须在独立试标开始前冻结，不能看完试标结果后调低。

| 指标 | 硬门槛 | 同时报表 |
|---|---:|---|
| 结构完整率、ID/版本匹配率 | 100% | 错误清单 |
| scope_state κ / 原始一致率 | ≥0.80 / ≥0.92 | 3×3 矩阵 |
| risk_state κ / 原始一致率 | ≥0.75 / ≥0.84 | 阳性比例、矩阵 |
| severity quadratic κ / exact | ≥0.75 / ≥0.72 | S3 分歧 |
| escalation κ / 原始一致率 | ≥0.80 / ≥0.88 | YES 阳性一致率 |
| response mode κ / 原始一致率 | ≥0.75 / ≥0.80 | 3×3 矩阵 |
| trigger/evidence/required/critical/prohibited/constraint mean IoU | 各 ≥0.67 | exact、Dice、空集比例 |
| S3 对 S0/S1 分歧 | 0 | query ID |
| required∩prohibited、critical⊄required | 0 | query ID |

25 条试标的 κ 置信区间预计较宽，所以 CI 用于不确定性说明和是否扩大试标，不把下限作为
机械唯一门槛。若某受控类别在任一标注者中少于 3 条，不作该类别稳定性的强结论；可扩大到
30–50 条新题复测。门槛通过仅允许进入仲裁，不证明医学正确。

## 7. 批准状态

当前状态：`METHODOLOGY_APPROVED_WITH_BLOCKING_PRECONDITIONS`。

阻断条件：风险、动作、约束本体必须由真实 C 逐项审核并冻结；C、S、T 必须在门槛文件登记
真实 reviewer ID 和日期。满足前述条件后，主持人把状态改为 `approved`，不得由 AI 代签。

一致性研究的人员、样本、独立性、盲法、统计方法与不确定性报告参照 GRRAS 的透明报告要求：
<https://www.equator-network.org/reporting-guidelines-study-design/reliability-and-agreement-studies/>。
