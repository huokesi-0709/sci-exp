# SC-EA-RAG 输入级协议 Gold 项目说明书

版本：v1.0-draft  
面向对象：标注者、领域审核者、导师和数据管理员

## 1. 项目目的

本项目研究资源受限边缘设备上的离线应急 RAG。系统需要针对每条查询选择满足协议安全
约束的最低能耗配置。为训练和评价这种选择机制，需要先建立独立于模型输出的输入级协议
Gold。

输入级协议 Gold 的目标不是判断用户的真实诊断，而是判断：

1. 查询是否出现冻结协议定义的风险触发信息；
2. 协议支持哪些必要行动、禁止行动和升级需求；
3. 建议成立需要保留哪些条件、顺序、主体和例外；
4. 上述判断由哪些协议证据直接支撑；
5. 信息或证据不足时，系统应直接指导、条件性指导还是安全回退。

## 2. 研究边界

### 包含

- 合成、公开或完成合法去标识处理的公众应急查询；
- 冻结版本的权威公众协议；
- 协议一致性、行动集合和证据跨度标注；
- 两名标注者的独立判断及领域人员仲裁。

### 不包含

- 真实患者诊断、治疗、处方或个体化临床决策；
- 以模型预测、检索排名或已有标签作为人工判断答案；
- 通过脚本制造第二名标注者；
- 把当前 400 条开发数据自动升级为确认性 Gold；
- 以本数据证明系统在现实灾害中必然安全有效。

## 3. 最小标注单位

最小单位为冻结的：

```text
query_id + query_text + observable_context + protocol_corpus_version
```

同一 `query_id` 的 A/B 标注必须针对完全相同的文本和协议版本。文本或协议变化后必须生成
新版本，不能在旧标签上静默修改。

## 4. 预期产物

- 经领域审核的标注手册和风险/动作本体；
- 培训题、试标题和正式题的分离清单；
- 原始 reviewer A 文件；
- 原始 reviewer B 文件；
- 仲裁前一致性报告；
- 逐项仲裁文件；
- 质量门禁和异常记录；
- 哈希、版本和冻结 manifest；
- 论文 Methods、Results 和 Supplementary 可报告材料。

## 5. 人员与工作量模型

最低可行配置为两名独立标注者和一名领域审核/仲裁者。领域人员不需要完成所有机械字段，
但应完成：

- 正式标注前审核手册、本体和示例；
- 复核全部高风险、证据缺口和潜在危险冲突；
- 裁决所有 A/B 分歧；
- 随机抽检低风险一致项；
- 确认论文对专业边界的表述。

## 6. 与实验顺序的关系

- E0 硬件准备、代码测试和非正式 dry-run 可并行进行；
- 使用这些标签的正式训练前，训练标签必须完成仲裁和用途冻结；
- Gold Calibration 在阈值校准前冻结；
- Gold Test 在方法、阈值和分析计划冻结后才能启封使用；
- 输出级双审属于另一个工作包，不在本说明书范围内。

## 7. 合规与隐私

在招募外部人员前，由导师或所在单位确认标注活动是否需要伦理审批、豁免或“不属于人类
受试研究”的机构认定。不得自行在论文中声称免审。所有人员使用匿名 reviewer ID；真实
姓名、联系方式、证件和劳务信息不得写入公开数据。

如数据包含真实个人经历、患者信息或可识别文本，必须暂停并先完成隐私、授权和伦理审查。

## 8. 成功标准

一个批次只有同时满足以下条件才能冻结：

- A/B 原始文件真实独立且完整；
- 使用同一查询、手册、语料和本体版本；
- 已生成仲裁前一致性报告；
- 全部分歧和高风险记录完成领域仲裁或明确标记不可判定；
- 无必需/禁止动作直接冲突；
- 所有 evidence ID 存在且适用；
- 质量门禁达到预注册标准；
- 文件哈希、版本、用途和批准人均已记录。
