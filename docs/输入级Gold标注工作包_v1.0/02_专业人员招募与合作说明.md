## 一页邀请文本

### 项目名称

面向资源受限边缘设备的离线应急 RAG 协议一致性研究

### 项目简介

我们正在开展一项计算机系统研究，目标是在离线边缘设备上，根据查询风险和设备资源选择
适当的 RAG 配置。研究需要依据冻结的公众应急协议，对合成或公开查询建立输入级协议
Gold。标注只用于判断文本与指定协议的一致性，不用于真实患者诊断、治疗或现场指挥。

### 希望获得的协助

- 审核风险触发、严重度、必要行动、禁止行动和升级需求的定义；
- 审核动作字典、培训例题和边界案例；
- 对两名标注者的分歧进行协议依据下的仲裁；
- 复核全部高风险记录和随机抽取的低风险记录；
- 检查论文中对专业范围和局限性的表述。

### 不要求的工作

- 不要求诊断真实患者；
- 不要求为模型安全作临床认证；
- 不要求编写程序或统计代码；
- 不要求逐次审核相同文本的硬件能耗重复运行。
