# 主持人与 A/B/C 现场执行指南

版本：v1.1

## 1. 你作为主持人 P 要做什么

你是数据管理员和流程主持人，不是第三名标注者。你的工作是冻结、发放、催收、校验、统计
和留痕，不是在看到分歧后替 A/B 改答案。

### 开始前

1. 给 A、B、C 分配匿名 ID，核验资历并签署独立/保密/利益冲突声明；
2. 只把“人员登记信息”交导师，不在公开数据中放证件；
3. 把手册、64 条协议证据索引和经 C 审核的三套本体冻结为同一版本；
4. 保存文件 SHA-256；确认培训题和独立试标题、source group 均不重叠；
5. 培训题和试标题永久标记为 TRAINING/PILOT，不进入正式 Gold calibration/test。

### 发放顺序

1. 先把 C 工作包发给 C；C 完成本体审核和培训答案表；
2. C 签字后，把 A 工作簿发给 A，把 B 工作簿发给 B；不要把主持人总控表或 C 答案表发给 A/B；
3. A/B 先独立完成 25 条培训题；回收后再组织讲解；
4. 讲解时只展示经 C 审核的参考答案和证据，不展示谁错得更多；
5. 培训完成后，要求 A/B 清空讨论记录，在不讨论的情况下完成 25 条独立试标；
6. A/B 分别把原工作簿回传给你，文件名保持不变并追加提交时间；
7. 你复制到只读归档，计算哈希，做结构校验；先运行一致性脚本，后把分歧清单给 C；
8. C 只看分歧项，并复核 100% S3、升级 YES、evidence gap 以及预定比例的一致项；
9. 导师/统计复核者根据报告决定准入、补训或新题复测。

## 2. A/B 每条题的操作步骤

按固定顺序，不得跳字段：

1. 原样阅读 query，不补写没有出现的症状；
2. 判断 `scope_state`；
3. 选择 hazard family 和 query intent；
4. 在风险本体中查 trigger，填 risk_state 和 S0–S3；
5. 在 64 条协议索引中查直接适用 evidence，核对人群、辖区、日期和条件；
6. 判断 escalation 与 response mode；
7. 从统一动作本体选择 required/critical/prohibited；
8. 从约束本体选择条件和顺序；
9. evidence gap 或 Unknown 时填写 uncertainty code；
10. 写 1–3 句 rationale，说明决定性文本、证据和仍缺什么；
11. 完成自检并填写带时区的完成时间。

A/B 禁止：查看旧 development 标签；搜索模型答案；互相讨论试标题；临时创造 ID；为提高一致性
而统一答案；把专业处置经验写成没有协议支持的公众行动。

## 3. C 的操作步骤

### 培训前领域审核

1. 审核 S0–S3 和三种 response mode 的边界；
2. 逐行审核风险触发候选，决定 APPROVE/MERGE/SPLIT/EXCLUDE；
3. 把复合动作拆成原子动作，逐条绑定直接 evidence；
4. 建立约束并指向 action；
5. 独立完成 25 条培训参考答案；
6. 对证据不足的题标记 UNRESOLVED/EXCLUDE，不强填。

### 试标后仲裁

1. 只在 A/B 文件锁定且一致性报告生成后开始；
2. 对每个分歧字段选择 A、B、NEW、UNRESOLVED 或 EXCLUDE；
3. 选择 NEW 时必须写出为什么 A/B 都不对及直接 evidence ID；
4. 仲裁不能只看多数票或“更像常识”的答案；
5. 若发现手册/本体缺陷，暂停同类项目，发布新版本并做影响分析；
6. 不得把仲裁后结果回写成 A/B 原始一致。

## 4. 回收形式

优先回收原始 `.xlsx`，不让标注者复制粘贴到聊天或重新排版。每人只提交自己的工作簿，
保留所有行，包括无法判断的行。主持人收到后：

- 文件名追加 `_submitted_YYYYMMDD-HHMM`；
- 保存只读副本并记录 SHA-256；
- 不修改内容；结构错误由原标注者在新版本修复并写 change log；
- 把 A/B 的 PILOT 表导出为 UTF-8 CSV 后交给一致性脚本；
- 把脚本报告和分歧表交 C，不把 B 的完整表发给 A，反之亦然。

你把 A/B 回收的两个工作簿原样放回工作空间后，可以让我负责转换、结构校验、运行一致性
脚本、生成分歧清单。你不需要自己手工计算 κ。

## 5. 一场推荐的组织节奏

| 日程 | 主持人动作 | A/B | C |
|---|---|---|---|
| D-7 至 D-3 | 核验资历、冻结材料 | 阅读手册 | 审本体和培训答案 |
| D-2 | 发培训题 | 独立作答 | 待答疑 |
| D-1 | 回收并组织 60–90 分钟培训 | 参加培训 | 讲解证据与边界 |
| D0 | 发独立试标 | 独立盲标 | 不介入 |
| D1 | 锁定、哈希、计算一致性 | 不回改 | 接收分歧清单 |
| D2 | 组织仲裁和门禁会议 | 仅回答过程性问题 | 仲裁和复核高风险 |
| D3 | 记录准入决定 | 获取资格状态 | 签署领域意见 |

如任何一天本体版本变化，独立试标必须换一套未见过的新题，不得继续沿用旧题计算准入。
